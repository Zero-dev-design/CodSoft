# Personal Portfolio Website

## Description

A responsive personal portfolio website developed using Flask, HTML, CSS, and JavaScript.

The website showcases:

* Personal Introduction
* About Me Section
* Skills & Expertise
* Project Showcase
* Contact Form
* Responsive Design
* Interactive Animations

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* SMTP Email Integration

## Installation

1. Clone the repository.
2. Install required dependencies:

pip install flask

3. Open the main application file.

4. Configure your email credentials before running the application:

```python
# YOUR EMAIL CONFIG
EMAIL_ADDRESS = ""
EMAIL_PASSWORD = ""
```

Replace:

* EMAIL_ADDRESS with your email address.
* EMAIL_PASSWORD with the App Password generated for your email account.

Note:
Do not use your actual email password. Use an App Password generated through your email provider.

5. Run the application:

python app.py

6. Open the browser and visit:

http://127.0.0.1:5000
